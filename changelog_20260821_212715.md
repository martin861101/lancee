# Hermes session isolation and file-truthfulness fix — 2026-08-21 21:27:15 UTC

## Fixed

- Scoped Hermes preference storage to the authenticated workspace and user using
  the existing preference table. Legacy unscoped entries are no longer injected.
- Made Hermes native-session verification fail closed: a run is never started
  when the exact persisted session cannot be read or created.
- Prevented unverified file-success claims. A response that claims a saved file
  without a verified Lancee Files artifact now reports that the save could not
  be verified; internal paths are not exposed as downloads.
- Reconciled MCP regression fixtures with the current 49-tool public catalog.

## Regression coverage

- Added same-user cross-workspace preference isolation.
- Added same-workspace conversation separation, provider-reload session resume,
  cross-user thread denial, unavailable-session rejection, and unverified-file
  response coverage.
