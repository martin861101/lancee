# Authentication and auth visual update

## Changed

- Added dedicated `/signin`, `/signup`, and `/signup/confirm?token=...` client routes.
- Split landing-page sign-in and sign-up actions so each opens its matching route.
- Added email-first registration. The server stores only a hashed, 24-hour confirmation token until the user confirms the email and chooses a password.
- Added confirmation email delivery through the existing SMTP notification service.
- Added automatic session creation and navigation into the app after password setup.
- Added a moving auth-side orbit with the lancee mark in the centre and business capability icons orbiting it, with reduced-motion support.
- Preserved invitation registration and Codex device-authorization sign-in behavior.

## Configuration

Enable public signup with `ALLOW_REGISTRATION=true` and configure SMTP delivery with
`SMTP_ENABLED=true`, `SMTP_HOST`, `SMTP_PORT`, and `SMTP_FROM_EMAIL`.
