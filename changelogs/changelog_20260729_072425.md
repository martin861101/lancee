# Changelog 2026-07-29 07:24:25 UTC

## Codex permission-profile migration

- Fixed `workspaceWrite.readOnlyAccess is no longer supported` when starting a
  Codex turn.
- Removed legacy `sandbox` and `sandboxPolicy` fields from App Server requests.
- Added a managed `lancee-workspace` permission profile to each isolated
  `CODEX_HOME`.
- Restricted filesystem access to minimal runtime reads and the configured
  workspace root.
- Denied `/tmp` and `$TMPDIR` access for Codex tools.
- Kept tool network access disabled and `approvalPolicy` set to `never`.
- Extended the runtime verifier to assert the managed profile and confirm that
  deprecated sandbox fields are not sent.
