# Project review packages

- Removed the Client Comments Kanban lane and introduced the Board, Details,
  Files, Reviews, and Activity project navigation.
- Added a review-package composer for selecting multiple buckets, assigning
  image previews, writing a client message, and setting a deadline.
- Added durable package items with Waiting review, Needs changes, and Approved
  states, plus permanent review history and project review metrics.
- Attached client comments to their exact review item and bucket, and surfaced
  review state and comment counts on related project task and asset cards.
- Updated the tokenized client review page so one package can be reviewed in a
  single scroll with per-item approval or requested-change comments.
- Added persistent task completion checkboxes and image previews in project
  cards, file lists, package history, and public reviews.
- Preserved the existing artwork annotation workflow inside review packages.
- Added `pnpm verify:project-reviews` for the end-to-end persistence lifecycle.

## Verification

- `npm run build`
- `npm run lint` (passes with pre-existing storefront/template warnings)
- `npm run verify:durability`
- `npm run verify:project-reviews`
