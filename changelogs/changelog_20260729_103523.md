# Google Drive file picker fix — 2026-07-29 10:35 UTC

## Fixed

- Added Google Picker parameters to the existing `drive.file` OAuth flow so
  users can explicitly select existing Drive files and folders.
- Preserved the non-sensitive per-file permission instead of requesting broad
  read access to an entire Drive account.
- Return Files-page OAuth requests to the Files page after selection while
  keeping Connections-page requests on Connections.
- Automatically load selected Drive items when the Files page opens.
- Added a visible empty state and **Choose Drive files** action when Google
  returns an empty file list.
- Corrected the Drive results layout so file cards are not nested inside the
  storage-provider grid.

## Operator action

- Enable both **Google Drive API** and **Google Picker API** in the Google Cloud
  project.
- Existing connected users should click **Choose Drive files** once and select
  the files or folders they want lancee to display.
