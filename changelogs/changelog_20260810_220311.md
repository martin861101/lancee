# Files dashboard: Google Drive workspace folder

## Changed

- Made Google Picker folder-only and persisted the selected folder as the
  workspace's Google Drive root.
- Added an always-visible Drive folder browser with breadcrumbs, nested-folder
  navigation, search filtering, compact file actions, and responsive layout.
- Reused the existing Drive workspace to view PDFs/images and edit supported
  Markdown and Word-compatible files back in Google Drive.
- Routed Drive uploads and local-document syncs into the selected folder.
- Kept Drive resource linking and advanced tools available below the primary
  browser.
- Preserved the selected folder as the database root when files are uploaded
  or synced, preventing child files from becoming separate workspace roots.

## Verification

- `npm run build` passes.
