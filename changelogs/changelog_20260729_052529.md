# Changelog 2026-07-29 05:25:29 UTC

## Codex AI connector

- Added the `plugins/lancee-ai` Codex plugin with a bundled dependency-free
  stdio MCP server and focused skill.
- Added `connect`, `ai_status`, and `complete` MCP tools.
- Added a durable OAuth device authorization flow with ten-minute human codes,
  explicit in-app approval, one-time exchange, and thirty-day `ai:invoke`
  tokens.
- Added hashed-at-rest device codes and access tokens scoped to the approving
  user and workspace.
- Added authenticated Codex AI status and completion endpoints without exposing
  the configured provider API key.
- Added a dedicated responsive device approval screen to the React app.
- Added `pnpm verify:codex-connector`, covering the application, database,
  device flow, MCP bridge, and provider forwarding end to end.
- Added `docs/CODEX_AI_CONNECTOR.md` and plugin-local usage documentation.
