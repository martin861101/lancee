# Storefront editor and page modes

## Added

- Added a workspace storefront mode selector for **Store with checkout** and
  **Basic page**.
- Added a drag-and-drop storefront/page editor with hero, text, logo, product,
  and call-to-action sections.
- Added section reordering, section insertion, text editing, product editing,
  logo URL/upload support, and automatic browser persistence per workspace,
  mode, and template.
- Basic pages start without commerce blocks and hide the store-only motion
  preview.

## Verification

- `npm run build` passed.
- `npm run lint` passed with existing warnings in unrelated storefront/template
  files.
