# Safer Google Drive OAuth — 2026-07-28 23:15 UTC

## Fixed

- Added the production `/oauth/callback` route so the application exactly
  matches the URI already registered in Google Cloud:
  `https://agents.hygridtech.co.za/oauth/callback`.
- Retained `/api/google-drive/oauth/callback` as a compatibility alias.
- Replaced the restricted full-account `drive.readonly` scope with Google's
  non-sensitive per-file `drive.file` scope.
- Disabled incremental scope carry-over so a previous full-Drive grant cannot
  be silently included in a safer authorization.
- Reject and remove stored tokens that contain the old restricted Drive scope,
  forcing an explicit safe reconnection.
- Updated integration status so legacy broad-scope tokens are not shown as
  connected.

## Verification

- Confirmed the live database contains no existing Google Drive grants needing
  migration.
- Verified the authorization URL uses `/oauth/callback`, requests only
  `drive.file`, and sets `include_granted_scopes=false`.
- Verified both callback route behavior and the OAuth error redirect.
- Passed `pnpm build`, `pnpm lint`, `pnpm verify:google-drive`, and
  `pnpm verify:workspace-flows`.
