# Secure Playwright MCP artifacts — 2026-08-17

- Added approval-gated `browser_pdf`, which renders a validated public page as
  an A4 PDF and saves it only as a workspace artifact.
- Added read-only `browser_research`, which searches the public web then reads
  up to five resulting sources using the existing isolated Playwright worker.
- Preserved the browser security boundary: no interaction, credentials,
  downloads, uploads, JavaScript execution, or unvalidated network access.
- Updated the MCP, onboarding, and root README documentation.
- Updated the workspace-agent planner so PDF, presentation, report, and
  executive-brief requests select `pdf.create`, then pause for confirmation
  before saving the generated artifact to Files.
- Rendered sanitized Markdown in the chat widget instead of exposing Markdown
  syntax as plain text.
- Added downloadable attachment cards to completed chat file actions and a
  clear `Create & attach file` approval choice.
- Replaced plain generated PDFs with an isolated Playwright print renderer that
  supports colored title cards, page borders, styled headings, lists, tables,
  callouts, links, and page numbers; the dependency-free renderer remains as a
  Markdown-clean fallback when Chromium is unavailable.
- Fixed local file viewing by loading PDF and image previews through
  authenticated blob URLs, reporting preview errors, and retaining download
  access for every file type.
- Allowed only same-origin and in-memory `blob:` frames/objects in the app CSP
  so authenticated PDF previews are not blocked by the browser security policy.
