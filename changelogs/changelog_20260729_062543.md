# Changelog 2026-07-29 06:25:43 UTC

## Codex AI connection UI

- Added a visible **Codex AI** card to the Connections catalog for existing and
  newly created workspaces.
- Added a connection panel that accepts the device code shown by Codex, displays
  the requested scope and workspace, and supports approval or denial.

  refresh, and **Disconnect all devices** controls.
- Added workspace-scoped connection status and token revocation endpoints.
- Updated the end-to-end verifier to cover catalog visibility, connected state,
  multiple devices, and revocation.
