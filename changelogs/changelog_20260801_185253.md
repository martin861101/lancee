# Dashboard playback and Hermes primary provider

Date: 2026-08-01

## Fixed

- Changed the production AI configuration to select Hermes with the
  `hermes-agent` model. Existing Hermes endpoint and API-key secrets were left
  unchanged.
- Corrected both duplicate AI provider blocks in `.env`, preventing the later
  Gemini declaration from overriding Hermes at process startup.
- Fixed Storefront MP4 playback by bypassing service-worker caching for video,
  audio, and HTTP byte-range requests. Cache Storage cannot store `206 Partial
  Content` responses, which previously caused valid videos to fail and left
  browser controls disabled.
- Rotated the PWA shell cache from `v1` to `v2` so clients discard stale cached
  media and application-shell entries after deployment.
- Fixed the Storefront settings migration for strict SQLite databases by using
  a checked `INTEGER` boolean on SQLite and a native `BOOLEAN` on PostgreSQL.
  The invalid SQLite migration had put the production process into a restart
  loop before the dashboard could serve any of the new work.
- Rebuilt and recreated the authoritative Docker `app` service, confirmed its
  health and Redis connection, and stopped the redundant PM2 copy that was not
  serving the public port.
- Updated the durability verifier to include the built-in Lancee MCP service
  and assert that its `create_workflow` tool is present, while retaining the
  external browser-worker checks.
