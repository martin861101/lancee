# Landing tones, stronger grain, and tldraw Ideas

Date: 2026-07-29

## Changed

- Increased the neutral grain overlay opacity from `0.075` to `0.1` on the
  landing page and dashboard content background.
- Kept the existing navy theme and avoided gold, brown, or spotlight colouring.
- Split the landing page into alternating dark and warm off-white tones.
- Restyled feature and integration surfaces for the off-white sections while
  retaining glass transparency, angled offset shadows, and cool blue accents.
- Replaced the custom Konva Ideas canvas with the full default tldraw editor.
- Added named canvas tabs, create/delete board controls, responsive dark glass
  framing, local IndexedDB persistence, same-browser tab synchronization,
  bundled editor assets, and offline status messaging.
- Added `VITE_TLDRAW_LICENSE_KEY` to the environment template.
- Added the tldraw implementation and persistence documentation.
