# Changelog — 2026-07-26 14:12 UTC

## Modern public experience

- Added a complete responsive landing page before login.
- Added sticky public navigation, product preview, metrics, workflow,
  integration, security, and conversion sections.
- Added responsive desktop, tablet, and mobile layouts using the lancee design
  system without adding bitmap dependencies.
- Added a secure session-restoration screen and public-site return path.

## Authentication

- Replaced the demo authentication state with Express login, session restore,
  and logout endpoints.
- Added scrypt password hashing and an interactive no-echo rotation script.
- Stored only the administrator salt and hash in the ignored server `.env`.
- Added signed `HttpOnly`, `Secure`, `SameSite=Lax` sessions with 12-hour expiry.
- Added login rate limiting, origin validation, security headers, and no-store
  caching on sensitive state.
- Chose the first-party session model for the current server-backed platform;
  documented Firebase as a future identity provider rather than an authorization
  store.

## MCP platform feature

- Changed MCP from a removable integration into a capability included with every
  workspace.
- Added `available`, `pending`, and `approved` bearer-access states.
- Added authenticated access-request, access-status, and revoke endpoints.
- Kept the DNS gateway and bearer credential behind the server boundary.
- Made the service catalog browsable before approval and activation controls
  available only after approval.
- Preserved the stable `/api/v1/tools/{tool_id}/call` integration contract.

## Notifications and environment

- Added server-only SMTP configuration and a lazy Nodemailer transport.
- Added authenticated SMTP status and test-message endpoints.
- Added a non-blocking notification hook for MCP access requests.
- Added `.env.example`, ignored `.env`/runtime secrets, and set the real `.env`
  permissions to `0600`.

## Validation

- `npm run build` passes.
- `node --check server/index.mjs` passes.
- `node --check server/notifications.mjs` passes.
- `npm run lint` completes with warnings only in retained reference templates.

## lancee rebrand

- Renamed the product from Nexus OS to lancee across the public site, login,
  workspace shell, API examples, server notifications, metadata, and current
  documentation.
- Integrated the supplied lancee icon and wordmark assets from `public/img`.
- Reworked the primary palette around the coral, pink, violet, and blue logo
  gradient while retaining green only for operational success states.
- Renamed newly issued session cookies to `lancee_session` with temporary
  read-and-clear compatibility for existing `nexus_session` cookies.
- Updated example API key prefixes to `lnc_*` and the n8n signature header to
  `X-Lancee-Signature`.
