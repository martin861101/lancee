# Architecture

## System Overview

```text
Browser
  |- TanStack Start frontend
  |    |- authenticated routes
  |    |- TanStack Query API state
  |    |- localStorage user configuration
  |    `- HTTP, SSE, and WebSocket clients
  |
  `- BaseBox agent on port 8787
       |- dashboard JWT authentication
       |- SSH and SFTP operations
       |- command and terminal streaming
       |- AI provider and Hermes proxies
       |- orchestration and research services
       |- encrypted SQLite persistence
       `- MCP management and public MCP transport
```

## Frontend

The frontend uses file-based TanStack Router routes under `src/routes`. Authenticated routes share the layout in `src/routes/_authenticated.tsx`, including the sidebar, header, command palette, and authentication guard.

Primary routes:

| URL | Purpose |
| --- | --- |
| `/dashboard` | Overview and server summary |
| `/monitoring` | Hardware, Docker, and PM2 monitoring |
| `/actions` | Streamed commands and operational tools |
| `/terminal` | Interactive SSH terminal |
| `/files` | Remote file browser and transfers |
| `/assistant` | AI chat and task execution |
| `/ai-settings` | Providers, agents, tools, skills, memory, and embeddings |
| `/services` | Documents, research, automation, orchestration, and swarms |
| `/automation` | Automation workspace |
| `/hermes` | Hermes gateway, memory, sessions, and failover |
| `/mcp` | MCP connections, health, client endpoint, and access keys |
| `/settings` | Agent URL, SSH servers, and appearance |

`src/lib/agent-client.ts` is the typed client for the backend. Requests use the configured agent URL, attach the dashboard bearer token, and abort after 15 seconds.

## Backend Agent

`agent/server.js` initializes Express, CORS, JSON body parsing, public health and MCP routes, dashboard authentication, and all protected routers.

Responsibilities include:

- SSH authentication and remote execution
- file listing, upload, download, creation, and removal
- WebSocket terminal sessions
- Docker and PM2 monitoring and lifecycle actions
- AI model discovery, chat streaming, and settings persistence
- local memory and embeddings
- orchestration pipelines and step caching
- browser research and extraction
- Hermes proxying and API-key failover
- WhatsApp configuration
- MCP connector storage, health testing, and external access

## Communication Protocols

| Protocol | Usage |
| --- | --- |
| JSON over HTTP | CRUD, settings, monitoring snapshots, and tool requests |
| Server-Sent Events | Command output, AI responses, and workflow logs |
| WebSocket | Interactive terminal at `/ws/terminal` |
| MCP Streamable HTTP | External JSON-RPC clients at `/mcp` |

## Authentication Boundaries

- `/health` is public.
- `/api/auth/login` is public and issues a 30-day dashboard JWT.
- `/api/auth/me` validates a dashboard JWT.
- Other `/api/*` routes require the dashboard JWT.
- `/mcp` uses separate hashed MCP access keys, not the dashboard JWT.
- The terminal WebSocket receives the dashboard token in its connection query.

## Persistence

SQLite state is initialized in `agent/lib/db.js`. Provider and SSH secrets are encrypted with AES-256-GCM using `agent/data/secret.key`.

Key tables:

| Table | Content |
| --- | --- |
| `servers` | SSH connection definitions and encrypted credentials |
| `kv` | Small encrypted or serialized settings |
| `pipelines` | Orchestration definitions and run metadata |
| `skills` | Backend skill definitions |
| `mcp_connections` | Encrypted connector configuration and health state |
| `mcp_api_keys` | Hashed external access keys and usage timestamps |
| `step_cache` | Expiring orchestration step results |

Additional JSON state, memory, sessions, and generated keys also live under `agent/data`.

## Generated Files

- `src/routeTree.gen.ts` is generated by TanStack Router.
- `.tanstack/` contains generated framework state.
- `dist/` contains build output.
- `agent/data/` contains runtime state and must not be committed.
