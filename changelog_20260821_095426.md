# Changelog — 2026-08-21 09:54:26 UTC

## Decision Intelligence experience

- Promoted **Intelligence** to a first-class authenticated workspace route at
  `/dashboard/intelligence` without changing the existing navigation or routing
  architecture.
- Added a calm, evidence-first Decision Intelligence page with an authoritative
  learning overview, exact persisted metrics, real relationship map,
  intelligence timeline, warning lifecycle, learned patterns, empirical
  predictions, bounded Decision Explorer, early-workspace states, and
  responsive detail drawer.
- Added provenance paths from patterns, predictions, and warnings to supporting
  decisions, measured outcomes, named confidence dimensions, evidence records,
  model versions, and causal-assessment assumptions.
- Kept evidence, pattern, prediction, warning, causal, inference, and
  expectation confidence separate. Predictions are described as estimates and
  observational changes as associations.
- Reused the existing warning acknowledgement/dismissal state and existing
  automatic resolution behavior. No second notification or review state was
  introduced.
- Integrated contextual **Ask Lancee** prompts with the existing persisted
  workspace assistant. Hermes remains an explanation boundary and is not a
  source of intelligence.

## Backend gap closed

- Added the read-only `get_decision_intelligence_overview` capability. It
  returns exact workspace-scoped counts, policy thresholds, active model
  provenance, real decision-object relationships, and up to 24 persisted
  intelligence events.
- The overview reads persisted results and never starts an intelligence refresh.
- No database table, migration, worker, scheduler, learning model, or duplicate
  intelligence entity was added.

## Existing architecture deliberately unchanged

- Decision Dynamics and Decision Learning remain authoritative for patterns,
  predictions, warning confidence, calibration, measured outcomes, and causal
  assessments.
- The Decision Vector taxonomy, confidence formulas, minimum sample threshold,
  warning threshold, workspace isolation, model versions, evidence provenance,
  and Hermes semantic boundary were not replaced or weakened.
- `list_decisions` remains the authoritative ledger. Empty pattern, prediction,
  warning, and review collections are explicitly presented only as empty within
  their own scope.
