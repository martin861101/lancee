# Changelog — 2026-08-06 09:13 UTC

## Fixed

- Prevented research prompts from sending Google search-result pages to the
  table-extraction MCP tool.
- Added a bounded built-in `web_search` tool for current public sources.
- Added a local `create_pdf` tool that saves valid PDF documents directly to
  the workspace Files library.
- Added a guarded continuation flow for research-to-PDF prompts: the user
  approves the read-only search first and approves the PDF write separately.
- Improved external MCP error cards to include available result details.

## Security

- Search results are labelled and handled as untrusted evidence; instructions
  embedded in external content are not treated as assistant instructions.
- Search has fixed server-side destination, response, result-count, and timeout
  bounds. PDF generation does not execute HTML or remote content.

## Delivered file

- Added `notable-baking-companies-2026-08-06.pdf` to the primary workspace Files
  library with 10 sourced company entries.
