# Add Dairy calendar and embedded Zoom meetings — 2026-08-22 05:24:08 UTC

## Added

- Added a new lazy-loaded **Dairy** dashboard route with separate Calendar and
  Meetings views.
- Added a responsive month calendar with project deadlines and workspace-scoped
  meeting scheduling linked to projects and clients.
- Added internal navigation between Calendar, Meetings, Projects, Clients, and
  Files.
- Installed Zoom Meeting SDK for Web 6.2.0 and dynamically load its component
  view only when a user joins a meeting.
- Added an authenticated server-side Zoom JWT signing endpoint, server-only SDK
  configuration, and the browser security policies required for embedded media.

## Development practices

- Preserved dashboard code splitting with a lazy page boundary and a second
  dynamic boundary around the Zoom SDK.
- Kept the Zoom secret on the server, validated meeting numbers, issued
  short-lived participant signatures, and disabled response caching.
- Added accessible tab state, explicit button types, responsive layouts, and
  unmount-safe async project/client loading.
- Documented setup and operational limits in `docs/DAIRY.md` and `README.md`.
