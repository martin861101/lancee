# Particle hero refresh fix

Date: 2026-07-30

## Fixed

- Fixed the landing hero becoming blank after a hard refresh.
- Stopped `html2canvas` from rendering directly into the hidden shader source
  canvas, which could produce a valid but empty initial texture.
- Captures now render into a detached canvas and are copied atomically into the
  source texture only after completion.
- The first capture waits for document fonts so the hero text and layout are
  stable before upload.
- Prevented an asynchronous capture from updating a destroyed particle
  renderer.
