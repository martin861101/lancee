# Files dashboard stale Google Drive selection fix

Date: 2026-08-10 21:17:10 UTC

## Fixed

- Prevented one deleted or inaccessible Google Drive selection from failing the
  entire Files dashboard with a `File not found: <id>` error.
- Changed selected-file metadata loading to keep available files and identify
  only the Google Drive IDs that return `404`.
- Added server-side cleanup for stale Drive selections, client/project resource
  links, and Drive sync pointers while preserving local workspace documents.

## Verification

- Added a Google Drive verifier case covering a mixed batch containing one
  available file and one missing file.
