# Basebox MCP integration finalized

Date: 2026-08-01

## Implemented

- Added Basebox as a first-class authenticated MCP service at
  `https://base-api.hygridtech.co.za/mcp`.
- Added negotiated Streamable HTTP sessions, protocol/session headers, JSON
  and SSE responses, bounded pagination, structured tool results, and
  best-effort session cleanup.
- Routed live Basebox discovery and invocation through the existing workspace
  activation, assistant confirmation, and invocation audit paths.
- Kept Basebox visible with an honest **Needs attention** state when its key is
  missing or rejected; removed mock/fallback tool behavior.
- Made MCP tool-level errors available as completed MCP responses instead of
  incorrectly treating them as transport failures.
- Improved the Services test action to choose only no-argument tools and show
  the returned data.
- Added deterministic and live Basebox verification commands.

## Configuration still required

The repository `.env` does not currently contain a Basebox access key. Add the
real value as `BASEBOX_MCP_ACCESS_KEY` and restart the app to make Basebox live.
