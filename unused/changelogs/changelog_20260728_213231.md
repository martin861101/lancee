# Changelog — 2026-07-28 21:32:31 UTC

## Replaced mock and disabled behavior

- Replaced `src/lib/mockApi.ts` with the real typed `src/lib/api.ts` client.
- Removed hard-coded MCP services and simulated tool results. Capabilities and
  calls now use the configured gateway from the server.
- Removed unsupported Stripe, PayPal, Dropbox, Figma, and email cards that
  could claim connection state without a provider transport.
- Disabled demo seeding by default; `SEED_DEMO_DATA=true` is now explicit.
- Replaced dashboard charts, run metrics, database metrics, notifications, and
  sidebar counts with persisted workspace data.
- Connected the Work travel-settings action and fixed project drag status so
  it persists after the optimistic UI move.
- Replaced static Settings controls with persisted timezone/travel settings,
  live database health checks, and working navigation; removed inert menu,
  filter, logo, run, and workspace-switcher buttons.
- Added real Google Drive disconnect, safe Drive file types, canvas link
  opening, remote HTTPS canvas images, AI result display, board-delete error
  handling, and working canvas share feedback.

## Server and data

- Added PostgreSQL connection pooling, TLS options, checked-out-client
  transactions, rollback, advisory idempotency locks, indexes, and query
  metrics.
- Kept SQLite as a durable single-process development fallback with foreign
  keys, WAL, busy timeout, and immutable payment-reference enforcement.
- Fixed payment and n8n row mappers that incorrectly reported configured
  providers as disconnected.
- Fixed Paystack reference lookup, payment-event duplicate detection,
  processed timestamps, and immutable reference integrity.
- Fixed n8n delivery argument mismatches and preserved encrypted secrets during
  configuration updates.
- Added durable automation completion/failure fields and signed n8n execution
  for saved automation runs.
- Added workspace API request metrics and corrected analytics calculations,
  zero-run success rate, seven-day activity, run duration, due dates, and
  database latency.
- Added transactional idea-board cleanup and project board unlinking.
- Added bounded validation and idempotency protection to project, idea,
  integration, cloud-link, MCP, API-key, and file mutations.

## Authentication and team access

- Wired `ALLOW_REGISTRATION` into the server and login UI.
- Replaced dummy-password team records with owner-only, seven-day,
  cryptographically random invitation links.
- Invitation tokens are stored as hashes and membership is created only after
  acceptance.
- Added SMTP invitation delivery with a copy/share fallback.
- Added an invitation acceptance screen for new and existing accounts.
- Removed the duplicate Team toolbar and added clear sent/share/failure state.
- Restricted team invitations, API-key visibility/creation/revocation, and
  workspace settings changes to workspace owners.

## Provider transports

- Added provider-correct OpenAI, Anthropic, and Gemini request/auth/response
  handling with timeouts, bounded input, normalized errors, and usage parsing.
- Added the server-side MCP capability and tool invocation transport.
- Kept Paystack, n8n, Google Drive, SMTP, AI, and MCP secrets out of the browser.
- Removed an exposed AI credential from `.env.example`. Any previously issued
  credential from that file must be revoked and replaced.

## Scalability and deployment

- Repaired Docker Compose PostgreSQL credentials and app connection variables.
- Removed the host-published PostgreSQL port.
- Added required strong password substitution and database health checks.
- Added a safe SQLite-to-PostgreSQL migration command:
  `pnpm migrate:postgres`.
- Added route-level lazy loading. The main production JavaScript chunk is about
  309 KB instead of roughly 770 KB before splitting.
- Pruned development dependencies from the runtime image and ensured the local
  runtime directory is created before SQLite opens.
- Added `docs/SCALABILITY_AND_POSTGRESQL.md` and updated README, platform,
  integration, authentication, n8n, Paystack, durable storage, and setup docs.
