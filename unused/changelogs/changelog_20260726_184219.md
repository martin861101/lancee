# Changelog — 2026-07-26 18:42:19 UTC

## Installable PWA and bounded offline sync

- Added a production web-app manifest and service worker with application-shell
  precaching, navigation fallback, cache-version cleanup, and static runtime
  caching.
- Explicitly excludes every API request and non-GET request from service-worker
  Cache Storage.
- Added a workspace-partitioned IndexedDB store for the last display identity,
  Idea-note snapshots, and queued Idea create/edit mutations.
- Restores only that bounded local state when an installed app reopens without
  the API, and clears it on explicit sign-out.
- Flushes queued Idea mutations immediately when possible, on reconnect, when
  the workspace is restored, and through a supported Background Sync handoff.
- Keeps payments, credentials, grants, integration configuration, and provider
  deliveries online-only.

## Durable Idea quick notes

- Added the workspace/board-scoped `idea_notes` SQLite table with creator,
  timestamps, and monotonic versions.
- Added authenticated read, idempotent create, and versioned edit routes.
- Uses client-generated note IDs and stable queued idempotency keys so lost
  responses can be replayed without duplicate records.
- Returns the current server note on stale-version `409` responses.
- Added visible queued and conflict states to Ideas, with explicit **Use
  server** and **Keep mine** resolution.

## Documentation

- Added `docs/OFFLINE_PWA.md` with install, cache, queue, security, conflict,
  route, schema, limitation, and verification details.
- Updated the README, getting-started guide, authentication notes, platform
  notes, durable-foundation guide, improvement plan, and decision review.
- Marked revised milestone 4 complete; Idea → Invoice is now the next suggested
  roadmap item.

## Verification

```bash
pnpm build
pnpm lint
pnpm verify:durability
pnpm verify:paystack
pnpm verify:n8n
pnpm verify:offline
node --check server/database.mjs
node --check server/index.mjs
node --check server/notifications.mjs
node --check server/paystack.mjs
node --check server/n8n.mjs
node --check public/sw.js
```

`verify:offline` uses a temporary SQLite database and local loopback server to
check the PWA boundary, durable note creation, idempotent replay, stale-version
conflicts, deliberate resolution, and restart persistence.
