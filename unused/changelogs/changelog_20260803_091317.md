# Changelog — 2026-08-03 09:13 UTC

## Messages dashboard and mail connector

- Added **Messages** to the dashboard sidebar and **Mail** to Connections.
- Added a responsive mail UI with folders, server-side search, message reading,
  sanitized HTML, compose/reply, Cc/Bcc, refresh, account health, and settings.
- Added automatic settings discovery for major providers and MX-based custom
  domains, with clear manual IMAP/SMTP instructions when discovery is
  inconclusive.
- Added owner-managed mailbox setup that verifies incoming and outgoing access
  before encrypting the credential with the workspace token vault.
- Added hostname validation, private-network blocking, TLS enforcement, message
  size limits, and server-side HTML sanitization.
- Added persistent mail accounts, native automation rules, and idempotent
  message-trigger records for PostgreSQL and SQLite.
- Added new-message polling and manual synchronization.
- Added rule matching for sender, recipient, subject, and subject/body keywords
  with all/any modes and instruction template fields.
- Enforced native Core-only execution for message rules in the UI, API, and
  dispatch path. Message triggers do not use n8n.
- Added `imapflow` and `mailparser`, the `verify:mail` check, environment
  examples, full connector documentation, and README coverage.
