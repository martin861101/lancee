# Changelog — 2026-07-26 18:08 UTC

## Paystack depth-first payment flow

- Added environment-backed Paystack `sk_test_`/`sk_live_` configuration while
  keeping the full secret out of the browser and database.
- Added workspace connection state with test/live mode and a non-secret key
  fingerprint.
- Added durable ZAR invoice, payment-link, and normalized webhook-event tables.
- Added immutable provider-reference triggers for invoices and payment links.
- Added idempotent hosted-checkout initialization through Paystack's
  `/transaction/initialize` API with a ten-second timeout.
- Added a public raw-body webhook route with constant-time HMAC-SHA512
  verification.
- Reconcile only signed `charge.success` events whose provider reference,
  amount, currency, and status exactly match the stored invoice.
- Deduplicate provider events and preserve paid state across restarts.

## Money experience

- Replaced fabricated invoice totals and records with persisted workspace
  invoices.
- Added honest Paystack unconfigured/test/live states while retaining Stripe
  and PayPal as labelled previews.
- Added an explicit client, email, project, amount, description, and due-date
  form.
- Return the hosted link for review/copy without sending it automatically.
- Added live outstanding/paid totals, provider status, refresh, checkout-link
  actions, and webhook-reconciled payment status.

## Verification and documentation

- Added `pnpm verify:paystack` with a local provider stub; it makes no external
  or real-money request.
- Verified provider request authentication and payload, single initialization
  across replay, conflict handling, signature rejection, amount mismatch,
  successful reconciliation, duplicate handling, secret absence, immutable
  references, and restart persistence.
- Added `docs/PAYSTACK.md` and updated the README, environment template,
  platform, integrations, getting-started, durable-foundation, improvement
  plan, and plan-review documents.
