# Changelog — 2026-08-01

## Durable Lancee scheduling and Hermes fallback

- Persisted Lancee MCP schedules in the `automation_schedules` database table.
- Added startup recovery, transactional due-row claiming, recurring dispatch,
  and schedule status/error tracking.
- Enabled bounded Python and JavaScript execution through the configured
  Lancee MCP subprocess runtime.
- Added Hermes fallback support for primary AI provider failures, including
  canonical `HERMES_ENDPOINT_URL` and `HERMES_API_KEY` settings plus legacy
  variable compatibility.
- Expanded connector and AI provider verification coverage and updated the
  project documentation.
