# Changelog — 2026-07-26 18:25:59 UTC

## Durable n8n webhook bridge

- Replaced the n8n preview with workspace-scoped, durable configuration and
  delivery history.
- Encrypts the shared signing secret at rest with AES-256-GCM and never returns
  it from configuration APIs.
- Restricts production webhooks to HTTPS, the configured exact n8n origin, and
  public DNS addresses; redirects and embedded credentials are rejected.
- Signs outbound GET and POST requests with a timestamp, nonce, exact path and
  body hash, stable correlation ID, and delivery ID.
- Added timeout-bounded outbound delivery, durable status/error recording,
  idempotent replays, and linked manual retry capped at five attempts.
- Added signed inbound GET and POST callbacks with a five-minute timestamp
  window and durable, workspace-scoped nonce replay protection.
- Added real Connections UI configuration, bidirectional contract checks,
  attempt history, retry controls, and disconnect behavior.
- Corrected the Paystack connection card so it opens the live Money flow while
  Stripe and PayPal remain explicitly labelled previews.

## Documentation

- Added `docs/N8N.md` with configuration, URL policy, signature contract,
  callback responses, retry behavior, persistence, routes, and verification.
- Updated the README, getting-started guide, platform/integration references,
  durable-foundation guide, improvement plan, and decision review.
