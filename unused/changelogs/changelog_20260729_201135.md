# License-free Ideas canvas, Kanban dragging, and delete controls

Date: 2026-07-29

## Fixed

- Removed `tldraw` and `@tldraw/assets`, eliminating the production license
  warning without suppressing or bypassing a license check.
- Replaced the Ideas editor with the MIT-licensed Excalidraw React package.
- Removed the now-unused Konva, React-Konva, and use-image dependencies.
- Removed `VITE_TLDRAW_LICENSE_KEY` from the application environment and
  deployment documentation.
- Preserved named idea boards and added debounced IndexedDB persistence for
  Excalidraw scene elements, view state, binary files, and reusable libraries.

## Changed

- Shifted the landing page light sections from warm off-white to a cool
  blue-grey mist that harmonizes with the navy dashboard.
- Made the active project card draggable between the In progress, Waiting on
  client, Review, and Completed lanes. Dropping persists the status through the
  existing project API; the lane buttons remain as keyboard-accessible controls.
- Added a visible, confirmed project delete action inside the project workspace.
- Added confirmed client deletion in the Clients panel. Projects remain in the
  workspace with their client relationship cleared; client-only Drive links are
  removed by the existing foreign-key policy.
- Added confirmed automation deletion. Associated automation run history is
  removed by the database cascade and immediately removed from client state.
- Kept Idea board deletion visible even when only one board remains.

## API and database

- Added `DELETE /api/clients/:id` and workspace-scoped client deletion.
- Added `DELETE /api/automations/:id` and workspace-scoped automation deletion.
- Extended the workspace-flow verifier to cover project status movement and
  both deletion paths.
