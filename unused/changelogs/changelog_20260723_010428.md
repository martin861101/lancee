# Dune vision implementation — 2026-07-23

## Changed

- Reviewed and applied the design direction in `public/vision/dune_design_language.md` and its accompanying concept image.
- Restricted sand to horizontal and shallow diagonal gusts that always enter from a side edge; particles can no longer fall from the top like rain.
- Reduced particle width, trail length, opacity, and velocity for finer airborne sand.
- Added a slowly travelling sun and atmospheric light arc to the dune canvas.
- Changed pointer interaction so it subtly influences light rather than moving the dune geometry.
- Added low-opacity topographic contour lines behind the landscape.
- Added a partially buried environmental `DUNE` word with an extremely slow, changing cast shadow.
- Replaced the generic Services marquee with a living workflow strip containing nine connected stages, a travelling signal, and sequential node responses.
- Added responsive and reduced-motion treatments for all new elements.
