# Landing particle scroll and animated headings

Date: 2026-07-30

## Added

- Added the standalone Canvas UI `ParticleScroll` React component with WebGL 2
  shaders, damped scroll progress, drifting grains, responsive sizing, and
  resource cleanup.
- Applied the requested particle configuration to the public landing narrative
  while keeping navigation outside the effect viewport.
- Added a masked, staggered reveal for the two hero title lines.
- Added one-time scroll-triggered reveals for landing-page `h2` and `h3`
  headings.

## Accessibility and fallback

- Preserved the complete native HTML landing page when experimental
  HTML-in-canvas support is unavailable.
- Avoided allocating WebGL or running an animation loop in fallback browsers.
- Disabled particle transitions and heading motion for visitors using
  `prefers-reduced-motion: reduce`.
- Kept the output canvas hidden from assistive technology and pointer input.

## Documentation

- Added `docs/LANDING_MOTION.md` with configuration, browser support,
  accessibility, performance, and maintenance details.
- Updated the README visual-system section.
