# Changelog — 2026-08-01 18:12 UTC

## Assistant and tools

- Replaced the `<lancee_action>` text-tag protocol with native structured tool
  calls for OpenAI-compatible/Hermes, Anthropic, and Gemini providers.
- Added the nine built-in Lancee tools to every authenticated workspace without
  requiring the optional external MCP gateway.
- Routed dashboard-approved built-in calls to the same Lancee MCP runtime used
  by the Codex connector and retained explicit human approval.
- Added assistant action polling and dashboard state refresh after workflow
  creation or execution.

## Workflows and automations

- Made assistant-created workflows active by default, with an explicit
  `activate: false` draft option.
- Added deterministic workflow status updates and kept the old toggle route for
  compatibility.
- Replaced selection-only workflow cards with executable Core recipes that
  create active database-backed automations.
- Enforced the saved tool permission list for read and write Core steps and
  migrated empty legacy Core permission lists to `workspace.summary`.
- Corrected `get_logs` warning-level filtering.

## Verification

- Expanded AI tests to cover structured calls for all supported provider
  formats.
- Expanded the connector verifier to prove dashboard assistant creation and
  execution plus all nine Lancee MCP functions.
- Fixed the stale Core/Edge verifier to read the approval token from the current
  `/review/:reviewId?token=…` URL.
- Added `npm run verify:platform` and documented the complete runtime in
  `docs/AUTOMATION_RUNTIME.md`.
