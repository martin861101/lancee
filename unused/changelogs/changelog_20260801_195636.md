# Automation outcomes visible in the dashboard

Date: 2026-08-01

## Fixed

- Added a first-class **Results** item to the Business navigation.
- Made the newest automation run and its outcome visible automatically.
- Added an explicit **View outcome** action to every run row.
- Rendered Core step results as readable counts, fields, and item cards while
  keeping full JSON and execution events available on demand.
- Added live polling while a selected run is still running.
- Made assistant-approved runs report a concise returned outcome and correctly
  show failed runs as failures.
- Persisted Edge/n8n callback `output`, `result`, or `summary` payloads as run
  events instead of discarding them after updating the status.

- `npm run verify:n8n`
