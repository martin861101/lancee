# Core/Edge security and execution completion

- Fixed PostgreSQL tenant transaction reuse and forced RLS on the integration-token vault.
- Added independent refresh-token IV/auth-tag storage and one-step master-key rotation support.
- Removed provider bearer tokens from persisted n8n delivery events; tokens are decrypted only for outbound delivery and legacy delivery records are scrubbed on startup.
- Added bounded retries for transient n8n failures and signed callback-driven automation completion/failure.
- Restricted n8n and integration-secret mutations to workspace owners.
- Added an optional private Docker Compose overlay for Redis-backed n8n Queue Mode with no public n8n or Redis ports.
- Expanded Core/Edge, n8n, and PostgreSQL verification coverage.
