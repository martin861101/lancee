# Changelog — 2026-08-03 — dashboard context, files, and navigation

## Added

- Replaced the static Home greeting with a live timezone-aware greeting, clock,
  location, and current weather card derived from the authenticated session's
  public IP.
- Added a modern dark file explorer with quick access cards, folders, files,
  search, storage meters, and responsive layout treatment based on the supplied
  reference image.
- Added local workspace, Google Drive, Dropbox, and Microsoft OneDrive storage
  choices, including named/default storage points and document associations.
- Added a desktop sidebar toggle with a smooth slide-out transition.
- Added a project-local PostCSS config so the dashboard build does not inherit
  an unrelated parent Tailwind configuration.

## Safety and behavior

- Public-IP geolocation and weather data are cached for 15 minutes and degrade
  gracefully when external providers are unavailable.
- Dropbox and OneDrive storage points are destination metadata only; the page
  does not browse those providers. Google Drive's existing optional browser and
  upload flow remains available.
- Added workspace database migrations for storage-point defaults and document
  associations.
