# Standard LLM tool calling

Date: 2026-08-01

## Changed

- Restored the existing Gemini configuration as the production primary LLM
  using `gemini-3.1-flash-lite`.
- Retained Hermes as an automatic, server-side fallback. Hermes is not a
  customer-facing requirement or a special gateway for tool execution.
- Preserved native Lancee tool calling for the primary LLM. The server continues
  to provide active workspace-scoped tool schemas and validate every proposed
  action before execution.
- Replaced technical workspace-chat wording such as “Tool request”, MCP errors,
  and “Approve & run” with plain-language confirmation and progress messages.

## Production behavior

- Ordinary questions are answered by the configured standard LLM.
- Requests to create, run, search, inspect, or schedule workflows can produce a
  native tool call from that same LLM.
- Changes execute only after the user selects **Confirm** in the dashboard.
- Provider credentials, MCP schemas, workspace authorization, and execution
  details remain server-side.
