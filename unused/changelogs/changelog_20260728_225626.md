# Connections, settings, and project attachments — 2026-07-28 22:56 UTC

## Fixed

- Google Drive now starts OAuth directly from the Connections card and returns
  to the Connections page with a visible success or error result.
- Paystack can be connected independently per workspace from Connections.
  Secret keys are AES-256-GCM encrypted, never returned to the browser, and
  paired with a workspace-scoped webhook URL.
- Paystack, Google Drive, and n8n connection status now comes from each
  provider's durable backend state rather than a generic toggle.
- MCP is separated from business connections and defaults to browser
  automation and utility categories only.
- Settings PATCH requests preserve omitted fields, upsert missing settings,
  update the canonical workspace name, refresh the sidebar immediately, and
  display load/save failures.
- Same-origin mutations work on the actual listener as well as the configured
  public origin, fixing local Docker settings and project actions.
- New projects can include up to ten files of 10 MB each.
- Existing projects can upload, list, download, integrity-check, and delete
  authenticated attachments.

## Data and operations

- Added encrypted Paystack credential storage to `payment_connections`.
- Added attachment content and SHA-256 columns to `project_files`.
- Rebuilt the Compose application and applied the additive PostgreSQL schema
  changes without resetting the fresh database.
- Added `pnpm verify:workspace-flows` and extended MCP verification to reject a
  business-data service outside the configured category allowlist.
