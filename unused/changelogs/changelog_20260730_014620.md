# Reference-matched particle scroll

Date: 2026-07-30

## Fixed

- Compared the landing implementation against the React source in
  `particle_scroll.md`.
- Identified that the custom standard-browser fallback rendered generic blue
  particles instead of dissolving pixels from the actual page.
- Added DOM viewport capture with `html2canvas` and routed those snapshots
  through the canonical WebGL texture, row-progress, and particle shaders.
- Kept the experimental HTML-in-canvas path unchanged for browsers that support
  it.
- Retained the lightweight 2D renderer only when WebGL 2 is unavailable.

## Interaction and performance

- Preserved the native interactive HTML beneath the pointer-transparent output
  canvas.
- Debounced snapshot refreshes during scrolling.
- Capped snapshot and canvas resolution at a `2x` device pixel ratio.
- Kept reduced-motion handling and renderer cleanup intact.
