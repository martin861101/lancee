# Changelog — 2026-07-26 17:50 UTC

## Durable workspace foundation

- Added a SQLite database at `.runtime/lancee.sqlite` by default with foreign
  keys, WAL, full synchronous durability, strict tables, a busy timeout, and
  enforced mode `0600`.
- Added durable `users`, `workspaces`, and `workspace_members` records.
- Changed login and session restoration to authorize through database
  membership while retaining compatibility for sessions issued before the
  migration.
- Added `WORKSPACE_ID`, `WORKSPACE_NAME`, and `DATABASE_PATH` configuration.

## MCP persistence

- Moved bearer access from process memory to workspace-scoped `mcp_access`
  rows.
- Added persisted `mcp_service_state` rows and real service activation routes.
- Made revoke deactivate all services in the workspace.
- Kept catalog discovery and tool execution clearly marked as placeholders.

## API-key security

- Replaced seeded in-memory API keys with authenticated backend list, create,
  and revoke routes.
- Added explicit `workspace:read` and `mcp:read` scopes.
- Hash high-entropy secrets at rest and return the full value only in the
  logical creation response.
- Added masked list values, `last_used_at`, revocation timestamps, and bearer
  enforcement on live workspace/MCP read routes.
- Updated the API-key UI for permission selection, masked durable records, and
  real timestamp display.

## Idempotency

- Added workspace-and-route-scoped idempotency records for MCP and API-key
  mutations.
- Reject missing keys with `400`, reject payload conflicts with `409`, and
  replay matching responses with `Idempotency-Replayed: true`.
- Reconstruct creation secrets for safe retries without storing plaintext.

## Verification and documentation

- Added `pnpm verify:durability`, which starts the server twice and verifies
  membership-backed login, persistence, hashing, file permissions, scopes,
  `last_used_at`, idempotency, and revocation.
- Added `docs/DURABLE_FOUNDATION.md`.
- Updated the README, environment template, platform, authentication,
  integrations, getting-started, improvement-plan, and plan-review documents.
