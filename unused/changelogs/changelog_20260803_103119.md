# Changelog — 2026-08-03 10:31 UTC

## Notification, profile, and Google Drive fixes

- Fixed notification and profile popovers being rendered behind the dashboard
  background by raising the authenticated topbar stacking layer.
- Notifications now show all workspace activity, display unread state, support
  mark-as-read actions, and navigate to related projects or invoices.
- Added JPEG, PNG, and WebP profile image upload/removal in Settings, with the
  image available in the topbar, profile popover, and sidebar.
- Added explicit logout actions to the profile menu and Profile settings.
- Persisted Google Drive Picker selections per workspace and limited root
  browsing to those selections plus intentionally linked or synced files.
- Added no-store cache handling, stale tree-state resets, on-demand folder
  loading feedback, and the ability to move deletable Drive files to trash.
- Updated the README product-area documentation for these capabilities.
