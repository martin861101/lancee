# OpenConnector integration gateway

Implemented the `OpenConnector.md` plan against OpenConnector 1.3.5 / commit
`e298b5aa13e899a3e77d519e7c9ee3104e1fc5d1`.

## Changes

- Added an isolated OpenConnector HTTP adapter with runtime/admin auth,
  timeouts, bounded retries, idempotent read retries, health checks, response
  limits, and normalized errors.
- Added the workspace-scoped IntegrationGateway service with dynamic action
  search/description/execution, connection ownership validation, hierarchical
  permissions, Lancee risk classification, output redaction, and durable audit.
- Added `integration_connections` and `integration_executions`, PostgreSQL RLS,
  SQLite support, and SQLite-to-PostgreSQL migration coverage.
- Added feature-gated MCP tools `integrations_search`,
  `integrations_describe`, `integrations_connections`, and
  `integrations_execute` through the existing Lancee registry.
- Added authenticated management/action APIs and the public OAuth callback
  proxy without exposing the OpenConnector admin/runtime services.
- Extended the existing Connections UI with provider catalog, status,
  connect/reconnect/disconnect, scopes, and health.
- Added the private OpenConnector 1.3.5 Compose service and environment
  template.
- Added `scripts/verify-openconnector.mjs` with mocked end-to-end coverage.
