# Changelog — 2026-08-01

## Storefront, custom domains, and MCP actions

- Added a Storefront dashboard tab with an opt-in switch and the bundled
  `storefront_black_white` template preview. The choice is persisted per
  workspace.
- Kept the MP4 product preview visible while the storefront is disabled, so
  users can evaluate it before opting in.
- Added a prominent play/pause control and removed the misleading disabled
  appearance from the selected template button.
- Added a Remotion `StorefrontPreview` composition and isolated render package
  for producing `public/storefront-preview.mp4`.
- Added workspace-scoped custom-domain records, guided DNS TXT/CNAME
  instructions, verification, and removal through the dashboard UI.
- Fixed MCP invocation to use the live runtime tool name when a catalog id is
  presented by the platform gateway.
- Added explicit MCP action proposals and an approval button to the workspace
  assistant, including nested JSON argument parsing and empty-text responses.
