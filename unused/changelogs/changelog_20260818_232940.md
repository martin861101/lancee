# Playwright invoice PDFs and bank transfers — 2026-08-18

- Replaced HTML invoice downloads with authenticated, server-side A4 PDF
  generation through the existing Playwright browser worker.
- Added four visually distinct invoice styles: Modern, Classic, Studio, and
  Minimal.
- Added six curated brand colours plus a custom colour picker, with automatic
  readable foreground colour selection in generated documents.
- Added direct bank-transfer payment details (account holder, bank, account
  number, optional branch code, and optional SWIFT/BIC) as an alternative to
  configuring Paystack.
- Preserved Paystack hosted checkout and now includes its payment URL in the
  generated PDF.
- Added reusable invoice-document cards with PDF regeneration and automatic
  first download after creation.
- Added renderer input validation, HTML escaping, network-disabled browser
  contexts, and a 10 MB PDF cap.
- Added `docs/INVOICE_PDFS.md` and `npm run verify:invoice-pdf`.
- Verified all four styles as single-page A4 PDFs, visually inspected their
  output, and passed the production build and lint (pre-existing storefront
  warnings remain).
