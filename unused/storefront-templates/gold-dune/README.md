# Hookit Easy — Gold

A cinematic single-page studio site built with React, TypeScript, Vite, GSAP, and a custom canvas-rendered hero.

## Features

- Animated gold dunes rendered on HTML Canvas with pointer interaction
- Procedural sand grain gusts and page-wide grain texture
- Glass-panel UI with gold tint and blur effects
- Shiny text animations
- Responsive, reduced-motion support

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
```
