# Storefront template sources

These are workspace-local copies of the four React templates from
`/home/apps/react-templates`:

- `blue-splash`
- `gold-dune`
- `red-tech`
- `gsap-flowish`

The dashboard storefront picker uses the same product-scroll, cart, and
checkout animation flow for each style. The template folders remain source
snapshots so they can be adapted into the Saleor storefront without changing
the dashboard build or requiring their separate dependency trees.
