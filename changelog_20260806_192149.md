# Local MCP server

- Added `server/mcp-grid-server.mjs` with MCP JSON-RPC support for all 29
  selected MCP Grid actions and 15 reusable workflows exposed as prompts.
- Mounted the MCP endpoint at `POST /mcp` on the existing application server,
  so the platform and MCP service ship in one app and one public port.
- Delegated action execution to the configured MCP Grid gateway, including the
  existing `/home/apps/mcp` backend, while keeping the gateway token server-side.
- Added stdio and standalone HTTP launch scripts, client configuration, and
  `MCP_SERVER_TOKEN` documentation.
