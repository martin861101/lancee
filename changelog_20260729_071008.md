# Changelog 2026-07-29 07:10:08 UTC

## Codex device-login fix

- Fixed `failed to request device code` from `codex app-server` in the
  production container.
- Added the Debian `ca-certificates` package so Codex's native HTTP client can
  validate TLS for `https://auth.openai.com`.
- Added the Debian `bubblewrap` package required by the Linux Codex sandbox.
- Documented why Node HTTPS checks could pass while the Codex binary still
  failed without the operating-system CA bundle.

## Diagnosis

- Confirmed container DNS returns valid IPv4 and IPv6 OpenAI addresses.
- Confirmed IPv4 HTTPS reaches the OpenAI device-auth endpoint.
- Confirmed `/etc/ssl/certs/ca-certificates.crt` was absent in the previous
  `node:22-bookworm-slim` runtime image.
- Reproduced the failure through a direct App Server
  `account/login/start` request before applying the image fix.
