# Portable landing particle animation

Date: 2026-07-30

## Fixed

- Removed the static-only behavior that made the landing particle effect appear
  broken in browsers without experimental HTML-in-canvas APIs.
- Added a portable 2D canvas particle renderer for Chrome, Safari, Firefox, and
  other standard browser configurations.
- Added continuous ambient drift plus scroll-reactive particle movement and
  trails so the effect is visible immediately and becomes stronger while
  scrolling.
- Preserved the enhanced WebGL renderer where its required APIs are available.

## Accessibility and performance

- The fallback respects `prefers-reduced-motion`.
- Rendering pauses when the page is hidden or the particle viewport is outside
  the visible page.
- Canvas resolution is capped at a 2x device pixel ratio and particle counts are
  bounded.
- All listeners, observers, and animation frames are cleaned up on unmount.

## Documentation

- Updated `README.md` and `docs/LANDING_MOTION.md` to describe the portable
  browser fallback and its runtime behavior.
