# WhatsApp Baileys connector

## Added

- Added an owner-scoped WhatsApp connector in Connections with QR pairing,
  status polling, disconnect cleanup, and a verified self-number guard.
- Added workspace-scoped private Baileys session directories under
  `.runtime/whatsapp`, with operations guidance for protecting that credential
  material.
- Added self-only test delivery and best-effort platform notification delivery
  for workspace setup, mail, and invoice events.
- Added `scripts/verify-whatsapp.mjs` for QR lifecycle, self-number mismatch,
  notification routing, and cleanup checks.

## Safety

- No arbitrary recipient is accepted by the API or assistant-facing connector.
- QR/connect/disconnect/test actions require the workspace owner; test sending
  requires explicit confirmation.
