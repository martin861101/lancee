# In-app Google Drive document workspace — 2026-07-29 11:07 UTC

## Added

- Added a full-screen lancee document workspace launched from Drive file cards.
- Added rich-text viewing and editing for selected Google Docs and DOCX files.
- Added Markdown source editing with a sanitized rendered preview.
- Added authenticated, inline PDF and image viewers.
- Added saving back to the original Drive file without broadening the existing
  non-sensitive `drive.file` OAuth grant.
- Added Drive version checks so a stale editor cannot overwrite a file changed
  by another collaborator.
- Added a 5 MB editable-source limit, HTML sanitization, authenticated preview
  proxying, and read-only handling based on Google Drive capabilities.
- Added external Google Drive fallback links for unsupported formats.

## Document fidelity

- Google Docs and DOCX conversion preserves semantic headings, lists, links,
  tables, images, and text emphasis.
- Suggestions, tracked changes, custom page layout, and some complex Word/Docs
  styling can be simplified when saved.
- PDF and image formats are view-only.

## Dependencies

- `mammoth` for DOCX-to-HTML conversion.
- `html-to-docx` for saving rich HTML back to DOCX.
- `sanitize-html` and `dompurify` for server and browser sanitization.
- `marked` for Markdown rendering.
