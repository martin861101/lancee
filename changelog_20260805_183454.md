# Workspace Builder implementation — 2026-08-05

## Added

- Implemented the complete ten-step Lancee Workspace Builder described in
  `NEW_FEATURES.md`.
- Added deterministic business profiles for modules, dashboards, permissions,
  templates, notifications, integrations, and automation drafts.
- Added optional AI workflow customization with strict response validation,
  explicit per-suggestion approval, and a safe no-provider fallback.
- Added durable setup state, resume behavior, completion timestamps, and a
  final generated manifest in `workspace_builder_configs`.
- Added owner-only builder APIs, validated workspace-logo upload, idempotent
  generation, and a completion notification.
- Added actual generation of selected draft automations and optional labelled
  sample client/project data.
- Added focused navigation based on the modules selected by a completed builder.
- Added a responsive, accessible interface with validation, saved-progress
  feedback, reduced-motion support, generation progress, retry behavior, and
  team-invitation handoff.
- Added `npm run verify:workspace-builder` and full implementation guidance in
  `docs/WORKSPACE_BUILDER.md`.

## Compatibility

- New workspaces are guided through setup automatically.
- Existing workspaces are not blocked and can launch the builder from the
  Platform section.
- Invitation-based members keep the existing join flow.
- SQLite, PostgreSQL, and the in-memory test database use the same new schema.

- `npm run build`
- `npm run lint` (passes with existing repository warnings)
- `npm run verify:workspace-builder`
