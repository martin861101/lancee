# Google Drive folder browsing — 2026-07-29 11:54 UTC

- Added secure folder-child listing using Google Drive's
  `'<folderId>' in parents` query.
- Added **Open folder** actions for selected Drive folders.
- Added breadcrumb navigation for root, nested folders, and return navigation.
- Added in-folder selection of supported files for the existing lancee viewer
  and editor.
- Added folder-specific empty guidance when `drive.file` has not granted access
