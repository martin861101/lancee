# Changelog — 2026-08-21 00:21:05 UTC

## Decision Intelligence Phase 2

- Added workspace-scoped scheduled outcome reviews with bounded future due
  dates, atomic due claiming, one-time workspace notifications, and completion
  when a non-pending measured outcome is recorded.
- Added append-only human confirmation, correction, and rejection of Hermes
  semantic comparisons. The machine assessment remains intact and Lancee
  recalculates the effective comparison confidence with
  `comparison-confidence-v1`.
- Added `decision_observation_reviews` and `decision_comparison_reviews` with
  checks, foreign keys, unique scheduling boundaries, and query/due indexes.
- Added four MCP capabilities: `schedule_decision_review`,
  `list_decision_reviews`, `get_decision_comparison`, and
  `review_decision_comparison`, preserving existing authorization, approval,
  audit, workspace isolation, and canonical result contracts.
- Routed decision, outcome, lesson, strategy, recommendation, and priority
  requests from the workspace assistant and constrained planner to the bounded
  Decision Intelligence tools. Added recent-decision/open-review context to the
  workspace snapshot and strengthened native Hermes instructions around
  evidence, confidence, correction, causality, and prediction boundaries.
- Preserved the existing bounded evidence-pack and contextual-only Hermes
  contract. Semantic failure continues to retain the structural comparison and
  mark the semantic stage unavailable.

## Compatibility fixes

- Sequenced Decision Intelligence reads that may share one PostgreSQL
  transaction client, removing the pg concurrent-query deprecation warning and
  preserving compatibility with the announced pg 9 behavior.
- Removed shared object identity between nested and top-level observation review
  results so the MCP cycle guard no longer removes the canonical review list.

## Real PostgreSQL verification

- Identified the deployment database server as `agent-app-db-1`, PostgreSQL
  16.14 (`db:5432` internally, host port `5433`).
- Ran the guarded verifier against an isolated
  `lancee_decision_verify_phase2_*` database on that server.
- Verified Phase 1 migration preservation plus Phase 2 tables, checks, indexes,
  foreign keys, deterministic and semantic comparison behavior, scheduled
  reviews, append-only human correction, final confidence, and two-workspace
  isolation.
- The temporary database was dropped. No production workspace or application
  data was modified.
