# Decision Intelligence Phase 1 — 2026-08-20

## Implemented

- Added the deterministic Session/Hermes/Lancee memory router and persistent,
  user-scoped Hermes preference store.
- Added the workspace activity ledger, connected-communication provenance
  boundary, Decision Candidate records, cheap signal filter, versioned confidence
  gate, retained human review results, and candidate promotion path.
- Added Decision, Decision Vector, expected reaction, metric, outcome, evidence,
  confounder, and comparison schemas and services.
- Added deterministic metric arithmetic, structural scoring, comparison
  confidence, evidence-conflict penalties, and confounder penalties while keeping
  causal confidence separate.
- Instrumented representative authorized project and file activity.
- Added seven Decision Dynamics MCP tools through the existing permission,
  approval, audit, and canonical-result contracts.
- Updated Hermes instructions, README, and Phase 1 implementation documentation.

## Acceptance result

The bumper example is represented and compared end to end. Lancee calculates
`1420 → 1221` as `-199` / `-14.01%`, returns the historical decision as a
structural candidate, exposes evidence confidence `0.91` and confounder-adjusted
causal confidence `0.32`, and leaves semantic comparability pending. No output
claims that the bumper caused the decline.
