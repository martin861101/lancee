# Frontend Structural Cleanup — Phase 0

Date: 2026-08-24 09:33:16 UTC

## Scope

Completed the controlled frontend structural refactor from
`tasks/UI_CLEANUP.md`. This phase changes ownership and loading boundaries only;
it does not redesign Connected Intelligence, add Phase 1 concepts, or change
backend/API behavior.

## Implemented

- Moved the existing Connected Intelligence and secondary Decision Intelligence
  UI intact from `src/components/dashboard/IntelligencePage.tsx` to
  `src/components/intelligence/ConnectedIntelligencePage.tsx`.
- Moved its already-isolated stylesheet to
  `src/components/intelligence/connected-intelligence.css` without changing
  selectors or declarations.
- Kept Connected Intelligence fetching, workspace scoping, findings, filters,
  opportunity cards, evidence drawer, See why interaction, connection map, and
  loading/error/empty states unchanged.
- Extracted the inline Home implementation and its workspace-pulse helpers into
  the lazy-loaded `src/components/OverviewPage.tsx` boundary.
- Reduced Home's typed interface to the user, runs, notifications, workspace
  context, analytics, navigation callback, and create-project callback it
  actually consumes.
- Extracted the shared shell icon and brand-mark primitives into
  `src/components/AppIcon.tsx` and `src/components/BrandMark.tsx` so Home does
  not depend on or form a cycle with `App.tsx`.
- Removed the orphaned Overview automation-prompt state and dispatch handler
  after verifying that the current Home implementation had no control capable
  of reading or invoking them.
- Updated source-based UI verification scripts to use the new Connected
  Intelligence path.

## Size

- `src/App.tsx`: 7,856 lines before; 7,122 lines after.
- `src/index.css`: 13,663 lines before and after. Connected Intelligence CSS was
  already feature-isolated, so no global CSS block was duplicated or rewritten.

## Intentionally retained in App.tsx

- Authentication and public auth/pricing routing.
- Workspace/session loading and switching.
- Navigation, sidebar, command palette, and top-level layout.
- Global integration, credential, automation, and settings modals/state.
- Existing large integration/settings implementations whose extraction was not
  required for the Connected Intelligence boundary and would increase risk.
