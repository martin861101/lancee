# Changelog — 2026-08-21 04:49:35 UTC

## Decision-input query correction

- Fixed a false inference where an empty `decision.list-reviews` result could
  be described as an absence of decisions, evidence, inputs, or schemas.
- Added deterministic routing from questions about decision inputs, rationale,
  criteria, context, evidence, or reasoning to `decision.list` in the
  constrained Lancee agent and to `list_decisions` in the direct workspace
  assistant.
- Questions containing a concrete decision ID read the decision and, within
  the run budget, its attached evidence.
- Clarified tool descriptions so `list_decisions` is the primary decision-input
  entry point and `list_decision_reviews` is only the outcome-review queue.
- Added `resultScope` and `emptyResultMeaning` to review-list results and
  preserved these fields through canonical MCP normalization.
- Updated Lancee, final responder, direct assistant, and native Hermes
  instructions to prohibit global absence claims from empty secondary
  collections and to avoid mentioning schemas unless one was inspected.
