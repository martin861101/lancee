# Connected Intelligence UI

Date: 2026-08-22

## Implemented

- Made Connected Intelligence the primary Intelligence page with the requested
  headline and supporting copy.
- Added real workspace counts for clients, projects, communications, meetings,
  invoices, time entries, and payments.
- Displayed active persisted `connected_opportunities` as detector-specific
  project meeting-load and client attention-load cards.
- Added evidence drill-downs that show persisted metrics, baselines, comparison
  record IDs, detector versions, and exact workspace-event references.

  meetings, messages, time entries, invoices, and payments.

  so Hermes can inspect the same workspace-scoped summary and opportunities.
- Preserved Decision Intelligence as an on-demand secondary history capability.
- Added the authenticated `GET /api/connected-intelligence/summary` endpoint.
