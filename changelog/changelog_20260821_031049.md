# Changelog — 2026-08-21 03:10:49 UTC

## Decision Intelligence Phase 3

- Added a deterministic, workspace-scoped autonomous intelligence cycle for
  calibrated structural scoring, measured-outcome pattern detection, empirical
  prediction, and proactive warnings.
- Added bounded structural-weight calibration from the latest explicit human
  comparison labels. Calibration requires eight labels with both classes,
  limits each base-weight adjustment to 20 percent, and stores the sample,
  class balance, training-data hash, parameters, and immutable model version.
- Added evidence-thresholded patterns using exact Decision Vector and metric
  signatures, minimum sample counts, source decision provenance, distribution
  statistics, and separate evidence, causal, and pattern confidence.
- Added empirical predictions with sample size, 95 percent interval, source
  decisions, confidence, model version, measured result, and absolute error.
- Added deduplicated proactive warnings only when sufficiently confident
  historical evidence contradicts a recorded expectation. Warnings can be
  acknowledged or dismissed and resolve automatically when the outcome is
  measured.
- Added observational association records and optional controlled before/after
  estimates with explicit design assumptions. Neither path asserts causal
  proof, and known confounders reduce inference confidence.
- Added `decision_learning_models`, `decision_patterns`,
  `decision_predictions`, `decision_warnings`, and
  `decision_causal_assessments` with workspace scope, checks, uniqueness,
  foreign keys, and indexes.
- Added seven MCP/capability tools for refreshing intelligence and reading or
  reviewing models, patterns, predictions, warnings, and causal assessments.
  Write paths retain human approval and all paths retain authentication,
  permissions, canonical result contracts, audit, and workspace isolation.
- Extended the direct workspace assistant and native Hermes instructions so
  decision-risk and forecast requests use persisted Lancee records and clearly
  distinguish every confidence dimension, empirical prediction, association,
  and assumption-dependent controlled estimate.
- Added the bounded autonomous pass to the existing scheduler at a maximum
  frequency of once every five minutes and 20 workspaces per pass.
