# Workspace switcher

Date: 2026-08-22

## Fixed

- Made the workspace name at the top of the sidebar an interactive switcher.
- Added an accessible workspace card with membership roles, current-workspace
  indication, outside-click and Escape handling, loading/error states, and an
  inline create-workspace form.
- Added authenticated APIs to list account workspaces, switch the active
  workspace session, and create a new owner workspace.
- Reloaded workspace-scoped dashboard state after a successful switch.
- Added workspace-flow coverage for listing, creating, unauthorized selection,
  switching, and session persistence.

## Verification

- `npm run build`
- `npm run verify:workspace-flows`
