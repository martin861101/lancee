# Hermes isolation and continuity fix

## Root cause

WorkspaceChat kept its thread only in React state. Hermes memory was scoped by
workspace and user, while asynchronous Hermes runs were not given explicit
Lancee history. The adapter also discarded structured Hermes file/artifact
results, so a saved file could not be reliably attached to the persisted run or
shown as a Lancee Files download.

## Changes

- Routed Hermes traffic to the named workspace profile
  `lancee_ws_<workspaceId>` and added fail-closed profile resolution. The
  default/personal Hermes profile is never selected.
- Added `HERMES_PROFILE_ENDPOINT_TEMPLATE` and
  `HERMES_PROFILE_API_KEYS_JSON` configuration for exposed, multi-workspace
  Hermes deployments.
- Scoped `X-Hermes-Session-Key` and `X-Hermes-Session-Id` to the authenticated
  workspace, user, named profile, and Lancee conversation.
- Reconstructed explicit `conversation_history` from the exact workspace/user/
  thread's persisted agent runs and linked artifacts.
- Persisted session creation/resume, profile, session, and run identifiers in
  safe usage/event metadata without logging prompts, content, keys, or tokens.
- Added workspace/user-scoped browser restoration and a server history query for
  WorkspaceChat. Unknown or unauthorized conversations fail closed.
- Validated Hermes file/artifact identifiers against the authenticated Lancee
  workspace, reused the existing artifact/document tables, linked artifacts to
  both the run and conversation, and returned download-ready file metadata.
- Sanitized internal filesystem paths from Hermes user-facing output.
- Extended `verify:agent` for same-conversation history, separate
  same-workspace conversations, cross-workspace isolation, named profile
  routing, profile failure, and artifact persistence.
- Investigated the MCP count discrepancy: the exact two exposed tools missing
  from the old fixture were `browser_pdf` and `browser_research`; the fixture
  now expects both.
- Documented Decision Intelligence readiness without claiming that the future
  structured decision schema, evaluation loop, or scheduled review product is
  implemented.

## Verification

- `npm run build` — passed.
- `npm run lint` — passed with existing repository warnings.
- `npm run verify:agent` — passed.
- `npm run verify:codex-connector` — passed after preserving the bounded
  assistant manifest's `create_pdf` entry when the exact two new tools are
  present. The exposed catalog now has 42 tools; the additions over the old
  40-tool expectation are `browser_pdf` and `browser_research`.

## Remaining deployment requirement

The exposed Hermes server must have the named Lancee workspace profiles and
workspace-authorized Lancee MCP credentials provisioned. If a workspace
profile key is absent, the agent request fails closed rather than using a
shared default profile.
