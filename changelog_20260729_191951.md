# Sandy grain and glass visual system

Date: 2026-07-29

## Changed

- Changed the public landing page from its light palette to the dashboard's
  dark navy theme.
- Added a warm sandy gradient and fine procedural grain layer inspired by
  `example_images/texture.png`.
- Positioned the dashboard atmosphere behind the content region only, starting
  after the sidebar and never overlaying navigation.
- Added the same atmospheric background behind the landing-page content.
- Converted primary dashboard and landing-page surfaces to translucent glass
  with subtle saturation, soft borders, and inset highlights.
- Added slightly offset shadows to cards, panels, dialogs, the landing preview,
  and the sidebar for a lifted, angled appearance.
- Preserved responsive sidebar behavior by extending the background across the
  viewport only when the mobile sidebar collapses.
