# Hookit Easy — Blue

A dark SaaS landing page template with 3D model, GSAP animations, and 6 sections. Built with React, TypeScript, Vite.

## Structure

- **Hero**: Split layout (text left, 3D scene right) with floating orbs + grid bg
- **Services**: 6 cards in responsive grid, ScrollTrigger fade-up
- **Stats**: 4-column stat bar
- **About**: Centered narrative
- **CTA**: Gradient CTA section
- **Footer**: Branded footer

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
