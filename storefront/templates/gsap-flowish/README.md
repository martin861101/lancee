# Hookit Easy — GSAP Template

A 3D portfolio template built with Next.js, React Three Fiber, GSAP, and Tailwind. Features 3D models, scroll-driven animations, and a dark theme.

## Tech Stack

- Next.js
- React Three Fiber / DREI
- GSAP
- Zustand
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
